# Dependencies

Minimum runtime for this setup on Fedora:

- `hyprland`
- `quickshell`
- `kitty`
- `network-manager-applet` / `nmcli`
- `jq`
- `wl-clipboard`
- `brightnessctl`
- `pam` + `gnome-keyring` + `libsecret` (`secret-tool`)
- `rofi` or `fuzzel` (depending on your launcher choice)
- `playerctl`
- `pavucontrol` or `pavucontrol-qt`

Optional:

- `matugen` (dynamic theming)
- `swww` or your preferred wallpaper daemon
- `clipse` / `cliphist`
- GitHub contribution widget token file:
  - `~/.config/quickshell/ii/secrets/github_token` (chmod `600`)
